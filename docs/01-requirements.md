# 01 用户、目标、范围与成功标准

选题：题号3，企业知识问答 Agent，帮助员工找到制度或产品问题的可靠答案。

输入为问题与可选user/assistant历史。知识库为合成JSON，提供文档ID、版本日期、章节与全文；本地SEARCH返回片段，READ支持指定章节。输出为回答、引用ID与逐字片段、资料缺口和任务状态，并保存实际动作、参数、Observation、后续动作和简要依据。

成功条件：明确问题有依据地回答；冲突读取双方并请求确认；资料外保持未知；相似改写能够查到相应资料；历史追问保留上下文；工具失败被模型观察并恢复或安全结束。引用必须来自本轮成功READ，不能用未读或错误版本片段；达到8轮/6次工具上限返回明确未完成状态。

D01与D02分别规定30/15个自然日，未提供适用范围、优先级和替代关系，不能擅自选15天。仅有D01且无冲突时允许据D01回答30天。替换移动端原文后，答案、引文和工具Observation应随资料变化；动作是否变化另行记录。

逐项结果、Real/Mock边界与失败见[题面核对](06-assignment-checklist.md)和[评估](03-evaluation.md)。范围为可安装CLI、自包含测试、实际示例和文档；不包含界面、部署、数据库、多Agent或生产级权限系统。
